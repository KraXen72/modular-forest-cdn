# modular-forest-cdn

This repository holds demo photo attachments for the [Modular Forest](https://github.com/KraXen72/modular-forest-qrapp) maintenance app prototype.

The app uploads each photo a technician attaches to an inspection or issue record as its own commit, at `attachments/<yyyy-mm>/<uuid>.jpg`. GitHub Pages serves the files at `https://kraxen72.github.io/modular-forest-cdn/<path>`. `.nojekyll` makes Pages publish them without a Jekyll build.

The photos are demo data from prototype sessions.
